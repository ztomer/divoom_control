# GOH_LINE_UNBOUNDED because its size is not ours to ratchet; and any file of our
# own held at a shrink-only ceiling (none today: the seven `ruff format` carried
# over 500 were split in D.SPLIT). A row may only FALL: split the file, lower its
# number, and delete the line (and its .gatesrc pattern) once it is <= 500.

# only warns, and a repo that adds an exemption for its own over-long code would
# get no ceiling and no failure -- which is the hole this whole mechanism was
# added to close (monitor, 2026-09-07).
